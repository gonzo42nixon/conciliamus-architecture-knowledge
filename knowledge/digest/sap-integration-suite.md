# SAP Integration Suite (Enterprise iPaaS)

## Begriff & Technische Einordnung
- **Akronym / Begriff:** `SAP Integration Suite`

## Bedeutung in der SAP-Welt
SAPs strategische Enterprise Integration Platform as a Service (iPaaS), bestehend aus Cloud Integration (CPI), API Management, Open Connectors, Integration Advisor und Event Mesh.

## Fundamentale technische Bedeutung (Real World)
Umfassende Cloud-Integrationsplattform (iPaaS) zur Verbindung heterogener Cloud-, On-Premise- und Non-SAP-Systeme mit vorgefertigten Konnektoren, API-Gateways und EIP-Routing.

## Kontext & Praxisbezug (BTP Integration Suite / Conciliamus)
Die zentrale Enterprise-Suite, auf der die beiden iFlows (IFL_MDM_BP_Batch_Receiver und IFL_MDM_BP_Item_Processor) für die Geschäftspartnersynchronisation betrieben werden.
