# Remote Function Call (SAP Netzwerkprotokoll)

## Begriff & Technische Einordnung
- **Akronym / Begriff:** `RFC`
- **Meilenstein / Epoche:** Klassisch / Zeitlos

## Bedeutung in der SAP-Welt
Proprietäres binäres Kommunikationsprotokoll zwischen SAP-Systemen und externen RFC-Connectoren

## Fundamentale technische Bedeutung (Real World)
Zustandsbehaftetes oder zustandsloses Remote Procedure Call Protokoll auf TCP-Basis mit SAP-spezifischer Datenkodierung.
