# HTTP 502 Bad Gateway (RFC 9110)

## Bedeutung in der SAP-Welt

## Fundamentale technische Bedeutung (Real World)
Server-Fehler: Ein Server fungierte als Gateway/Proxy und erhielt eine ungültige Antwort vom Upstream-Server.
