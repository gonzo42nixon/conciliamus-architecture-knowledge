# HTTP 504 Gateway Timeout (RFC 9110)

## Begriff & Technische Einordnung
- **Akronym / Begriff:** `504`
- **Meilenstein / Epoche:** Klassisch / Zeitlos
- **Kategorie:** `Status & HTTP`
- **Architektur-Ebene:** `Layer 2: OS, Netzwerk & Transport`
- **Impact-Score:** `65 / 100`

## Bedeutung in der SAP-Welt
Timeout des SAP Web Dispatchers oder BTP Routers bei extrem langsamen Backend-Operationen

## Fundamentale technische Bedeutung (Real World)
Server-Fehler: Der Gateway-Server erhielt nicht rechtzeitig eine Antwort vom Upstream-Backend.

## Kontext & Praxisbezug (BTP Integration Suite / Conciliamus)
Wird durch asynchrone Entkopplung via iFlow 1 Iterating Splitter konsequent verhindert.
